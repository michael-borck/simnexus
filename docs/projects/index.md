# Project Gallery

Hands-on, assessable student projects — one or two per simulator, organised by
modelling paradigm. Each lists its **difficulty**, **time**, and the **simulator**
it uses. New projects should follow the [Project Template](../project-template.md);
see the [Instructor Guide](../instructor-guide.md) and
[Assessment Guide](../assessment-guide.md) for how to run and grade them.

> Every project requires reproducibility (`random_seed`), validation against a
> known result, and interpretation of the output.
